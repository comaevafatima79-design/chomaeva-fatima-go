# Практическая работа 1

### Задание 3. Вопросы
- В файле `go.mod` хранится название нашего модуля и версия языка Go.
- Пакет `package main` сообщает Go, что мы пишем исполняемую программу, а не библиотеку.
- Функция `main()` — это главная точка входа, откуда начинается выполнение всей программы.
- В Go запрещены лишние неиспользуемые импорты, чтобы не мусорить в коде и чтобы проект быстрее компилировался.
- Команда `go run .` сразу компилирует и запускает код, а `go build .` собирает готовый exe-файл в папку.

### Задание 5. Ошибки
1. Удалила закрывающую фигурную скобку `}`:
- команда: `go run .`
- ошибка: `syntax error: unexpected EOF, expected }`
- это ошибка компиляции (синтаксис).
- исправила: поставила закрывающую скобку на место в конце функции.

2. Добавила неиспользуемый импорт `strings`:
- команда: `go run .`
- ошибка: `"strings" imported and not used`
- это ошибка компиляции.
- исправила: убрала строку `import "strings"`.

3. Переименовала `main` в `start`:
- команда: `go run .`
- ошибка: `function main is undeclared in the main package`
- это ошибка компиляции (программа не нашла главную функцию main).
- исправила: переименовала обратно в `main`.
